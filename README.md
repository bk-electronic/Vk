# AI Nexus

A professional AI SaaS platform similar to ChatGPT, built with Flask and vanilla JavaScript.

## Features

- **AI Chat**: Real-time chat with conversation history
- **Text Generator**: Generate content in different tones
- **Hashtag Generator**: Create relevant hashtags
- **Image Prompt Generator**: Generate detailed prompts for AI image tools

## Setup

1. Install dependencies:
   ```
   pip install flask
   ```

2. Set your OpenRouter API key:
   ```
   export OPENROUTER_API_KEY=your_api_key_here
   ```

3. Run the app:
   ```
   python app.py
   ```

4. Open http://127.0.0.1:5000 in your browser.

## Tech Stack

- Backend: Flask (Python)
- Frontend: HTML, CSS, JavaScript
- API: OpenRouter (compatible with OpenAI)
